# Configs

GSSG configs are **layered**: a child config names a `parent:` and overrides only what it
needs. `gssg/utils/config_utils.py` walks the chain to the root (`parent: "None"`) and merges,
child-over-parent. The resolved config is written to `<save_path>/config.yaml` so any run is
re-runnable.

```
base.yaml                     ← every default lives here (root)
  └── quality/*               ← speed/quality preset (swappable via --quality)
        └── datasets/*         ← input identity ONLY: reader type, paths, topics, sensor limits
              └── _scenes/*     ← a single scene: source_path + save_path
```

**Dataset configs must not contain quality/tuning keys.** Speed/quality dials live in
`quality/*`; `--quality {low|mid|high|mid_bench|live|replay}` swaps the first quality
ancestor in the chain, so the same dataset config runs at any quality without editing —
and without hidden dataset-layer overrides surviving the swap.

Quality presets: `low` (Jetson/preview), `mid` (balanced default), `high`,
`mid_bench` (= mid + ViT-H-14, the OpenLex3D benchmark preset), `live` (real-time
budget + out-of-core submapping — default parent of the ROS stream configs), `replay`
(= live minus real-time caps, for offline bag/SVO replay).

## Which config do I use?

Run through `bin/gssg-run` (resolves conda env, ROS, GPU engine automatically):

| Command | Config | Runner | Quality |
|---|---|---|---|
| `bin/gssg-run replica` | `datasets/replica.yaml` | `run.py` (single) | (config default: mid) |
| `bin/gssg-run zed` | `datasets/ros2_zed.yaml` | `run_mp.py` (multi) | (config default: live) |
| `bin/gssg-run ros2` / `online` | `datasets/ros2_online.yaml` | `run_mp.py` | (config default: live) |
| `bin/gssg-run <path-or-stem>` | any config under `configs/` | `run.py` | (config default) |
| `bin/gssg-run` (no args) / `new` | wizard → writes `_runs/<name>.yaml` | — | asked |

Or call a runner directly: `python gssg/run.py --config configs/datasets/replica.yaml --quality high`.

Bag replay example (no real-time constraint → use `replay`):

```bash
./bin/gssg-run ros2_zed --mp --quality replay
ros2 bag play <bag_dir> --rate 0.5
```

## Directory reference

| Dir | Contents |
|---|---|
| `base.yaml` | Root defaults for every parameter group. No tuning dials. |
| `quality/` | `low`, `mid`, `high`, `mid_bench`, `live`, `replay` presets (see above). |
| `datasets/` | One config per input: `replica`, `hm3d`, `clio`, `realworld_zed`, ROS streams (`ros2_zed`, `ros2_online`, `ros1_online`, `ros_offline`). |
| `_scenes/` | Example per-scene configs that set only `source_path` + `save_path` (`replica_room0`, `replica_office0`, `hm3d_00824`) plus `replica_office0_submap` (out-of-core submapping demo). Copy one per scene. |
| `_runs/` | Auto-generated by the wizard / benchmark scripts. **Gitignored** — local artifacts, not source. |

New per-run configs written by the wizard land in `_runs/` and are yours to keep or delete.
